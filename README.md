# Food Delivery Application – REST API

## Project Overview
A backend application developed using Java and Spring Boot to manage food delivery operations, including restaurants, food items, customers, delivery partners, and orders.

## Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Spring Security
- RESTful APIs
- Maven

## Features
- Restaurant and food item management
- Customer management
- Delivery partner management
- Order management
- CRUD operations using RESTful APIs
- Database integration using Spring Data JPA and MySQL
- API protection using Spring Security

## Architecture
The application follows a layered architecture:
- **Entity:** Represents database entities.
- **Controller:** Handles incoming REST API requests.
- **Service:** Implements business logic.
- **Repository:** Performs database operations.
- **SecurityConfig:** Configures application security.

## Setup Instructions
1. Clone this repository.
2. Open the project in Eclipse or another Java IDE.
3. Configure your MySQL database in `application.properties`.
4. Update the database username and password locally.
5. Run the application as a Spring Boot application.
6. Test the REST APIs using Postman.
